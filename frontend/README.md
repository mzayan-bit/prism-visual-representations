# PRISM Frontend

## Overview
This directory contains the Next.js TypeScript web interface for PRISM, dedicated to visualizing representation geometry, cross-paradigm benchmark scorecards, robustness sweeps, and comparative explainability maps.

## Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Package Manager**: npm

## Development
To start the local development server:

```bash
cd frontend
npm install
npm run dev
```

The application will be available at [http://localhost:3000](http://localhost:3000).

## Build & Validation
```bash
npm run lint
npm run build
```
