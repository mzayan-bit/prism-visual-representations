# PRISM Official Demonstration Artifacts

## Overview
This directory contains reproducible, publication-grade benchmark artifacts and synthesized research reports generated by `scripts/generate_demo.py` (or `make demo`).

## Contents
- `prism_demo_campaign.json`: Official PRISM Representation Showcase campaign configuration and research questions.
- `prism_demo_report.json`: Machine-readable structured research synthesis report with evidence-backed findings and Pareto frontiers.
- `prism_demo_report.md`: Formatted Markdown research report summarizing cross-architecture and cross-paradigm representation metrics.
- `benchmark_matrix.csv`: Tabular cross-architecture vs. pretraining-objective matrix.
- `benchmark_table.csv`: Comprehensive benchmark metric table with statistical aggregations across repeated seeds.

## Provenance
All values in these artifacts are deterministically derived using `scripts/generate_demo.py --seed 42`.
To regenerate:
```bash
make demo
```
