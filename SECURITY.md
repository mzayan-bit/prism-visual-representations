# Security Policy

## Supported Versions
PRISM is in active pre-alpha development. Security patches and fixes are applied to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within PRISM, please report it responsibly by contacting the maintainers via GitHub Security Advisories or by emailing the project maintainers directly.

Please include:
1. A description of the issue.
2. Steps to reproduce or a minimal proof of concept.
3. Potential impact of the vulnerability.

We appreciate your efforts to responsibly disclose findings and will respond promptly to verify and address reported issues.
