# PRISM Explainability (`prism.explainability`)

## Purpose
The `prism.explainability` module provides comparative interpretability methods across convolutional and attention-based visual models.

## Intended Responsibilities
- **CNN Interpretability**: Grad-CAM, integrated gradients, and activation maximization for convolutional networks.
- **Transformer Interpretability**: Attention rollout, attention heatmaps, and cross-attention attribution for Vision Transformers.
- **Comparative Attribution**: Side-by-side visualization showing how different inductive biases allocate spatial importance.
