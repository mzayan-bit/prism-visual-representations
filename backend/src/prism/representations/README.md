# PRISM Representations (`prism.representations`)

## Purpose
The `prism.representations` module provides tools to analyze, probe, and mathematically characterize internal visual representations across neural network architectures and learning paradigms.

## Intended Responsibilities
- **Centered Kernel Alignment (CKA)**: Linear and kernel CKA for layer-to-layer and paradigm-to-paradigm representation similarity.
- **Linear & Non-linear Probes**: Probing frozen intermediate features for semantic attribute decoding.
- **Intrinsic Dimensionality & Spectra**: Singular value spectrum analysis, effective rank, and geometric manifold characterization.
- **Class Separation & Geometry**: Silhouette scores, intra-class variance vs inter-class distance, and neural collapse analysis.
