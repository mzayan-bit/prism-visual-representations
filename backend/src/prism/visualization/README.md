# PRISM Visualization (`prism.visualization`)

## Purpose
The `prism.visualization` module handles figure generation, interactive embedding exports (UMAP/t-SNE/PCA data arrays), and visual rendering for research artifacts.

## Intended Responsibilities
- **Embedding Projection**: Computing and exporting 2D/3D projection coordinates and labels for frontend dashboard inspection.
- **Scientific Figures**: Generating publication-grade vector (SVG/PDF) and raster (PNG) comparison charts.
- **Attention Overlays**: Rendering calibrated heatmap overlays on source visual stimuli.
